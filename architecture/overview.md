## 核心模块设计

### 1. 记忆系统 (Memory System)

**三层架构：**

| 层级 | 存储内容 | 容量 | 技术实现 |
|------|----------|------|----------|
| **工作记忆** | 当前对话上下文 | 最近5-10轮 | 对话窗口缓存 |
| **情景记忆** | 事件记录 | 数月内 | 时间戳 + 事件图谱 + 向量检索 |
| **语义记忆** | 知识/偏好 | 长期 | 知识图谱 + 结构化数据库 |

**记忆提取流程：**
```
用户 Query → 语义检索 → 时序检索 → 关联检索 → 重要性加权 → 注入上下文
                                  ↓
                            对话结束后自动执行记忆更新
```

### 2. 搜索模块 (Search Engine)

**多源路由策略：**

```python
def route_search(query, user_context):
    if 包含(query, ["最新", "今天", "刚刚"]):
        return "news_search"      # 实时新闻源
    elif 包含(query, ["论文", "研究", "学术"]):
        return "academic_search"  # Google Scholar/ArXiv
    elif 包含(query, ["价格", "购买", "评测"]):
        return "commerce_search"  # 电商/评测网站
    elif 包含(query, ["代码", "bug", "API"]):
        return "code_search"      # GitHub/StackOverflow
    elif is_personal(query, user_context):
        return "memory_first"     # 先查个人知识库
    else:
        return "general_search"   # 通用搜索
```

**免费搜索源：**
- 通用搜索：DuckDuckGo API / SearXNG
- 学术搜索：ArXiv API / Semantic Scholar API
- 知识搜索：Wikipedia API
- 代码搜索：GitHub API

### 3. 知识库 (RAG)

**处理流程：**
```
用户上传文档 → 文本分块 → 向量化 → 存入向量库
       ↓
用户提问 → 语义检索 → 召回相关片段 → 结合LLM生成回答
```

**支持格式：**
- 文档：PDF、Word、PPT
- 网页：自动抓取正文
- 语音：语音转文字录入
- 聊天记录：可搜索历史对话

## 数据流设计

### 对话流程
```
用户输入
    ↓
意图识别 (需要搜索? 需要记忆? 纯对话?)
    ├─→ 纯对话 ──→ LLM 生成 ──→ 输出
    ├─→ 需记忆 ──→ 记忆检索 ──→ 注入上下文 ──→ LLM 生成 ──→ 输出
    │                                                     ↓
    │                                                记忆更新
    └─→ 需搜索 ──→ 搜索执行 ──→ 结果融合 ──→ 与记忆关联 ──→ LLM 生成
                                                           ↓
                                                      记忆更新
```

### 记忆存储流程
```
对话文本
    ↓
[1] 关键信息提取 (LLM Prompt)
    ↓
提取结果：
  - 事实型 → 语义记忆
  - 事件型 → 情景记忆  
  - 情感型 → 情感记忆 (带情绪标签)
    ↓
[2] 重要性评分 (1-10分)
    ↓
[3] 冲突检测
    ↓
[4] 存储入库 (高优先级立即持久化)
```

## 隐私与安全设计

### 本地优先架构
```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  本地设备   │ ←→ │  本地数据库  │ ←→ │  云端备份   │
│ (敏感数据)  │     │ (加密存储)  │     │ (端到端加密)│
└─────────────┘     └─────────────┘     └─────────────┘
```

**安全措施：**
- 敏感记忆（家庭、财务）本地存储，不上云
- 云端同步采用端到端加密
- 用户拥有完整数据导出权
- Prompt 注入检测
- 输出内容过滤

## 技术栈总结

| 层级 | 技术选型 | 理由 |
|------|----------|------|
| LLM | Qwen2.5-7B / Llama3-8B (Ollama) | 本地部署，质量与性能平衡 |
| 嵌入模型 | bge-small-zh / nomic-embed-text | 轻量级，本地运行 |
| 向量库 | Chroma | 单机部署，零门槛 |
| 结构化存储 | SQLite | 轻量，内置 Python |
| 后端 | Python + FastAPI | 生态丰富，异步支持 |
| 前端 | React + TypeScript | 跨平台，类型安全 |
| 桌面端 | Tauri | 轻量，安全 |
| 搜索 | DuckDuckGo + SearXNG | 免费，无 API Key |
| 部署 | Docker + Ollama | 容器化，环境一致 |
