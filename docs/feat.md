## 二、核心模块详细设计

### 1. 记忆系统（最核心）

这是让系统"懂你"的关键，分为三个层次：

| 记忆层级 | 存储内容 | 示例 | 技术实现 |
|---------|---------|------|---------|
| **短期记忆** | 当前对话上下文 | 刚才提到的项目 deadline | 对话窗口缓存 |
| **中期记忆** | 近期偏好、习惯 | 最近爱喝拿铁、在赶论文 | SQLite + 时间衰减权重 |
| **长期记忆** | 核心身份、价值观 | 职业、家庭、长期目标 | 向量数据库 + 结构化档案 |

**记忆提取机制：**
- 每次对话结束后，AI 自动提取关键信息
- 使用 NER（命名实体识别）+ 情感分析标注重要性
- 用户可主动说"记住我喜欢..."或"忘掉..."

### 2. 个人知识库（RAG 架构）

```
用户上传文档 → 文本分块 → 向量化 → 存入向量库
                                    ↓
用户提问 → 语义检索 → 召回相关片段 → 结合LLM生成回答
```

**支持的内容类型：**
- 工作文档（PDF、Word、PPT）
- 网页收藏（自动抓取正文）
- 笔记/日记（支持语音转文字录入）
- 聊天记录本身（可搜索历史对话）

### 3. 多领域问题解决能力

通过 **Function Calling / Agent 架构** 扩展能力：

| 领域 | 功能 | 实现方式 |
|-----|------|---------|
| 工作学习 | 文档总结、翻译、写作辅助 | LLM 原生能力 |
| 生活管理 | 日程提醒、记账、待办 | 集成日历/记账 API |
| 知识查询 | 实时新闻、天气、股票 | 搜索引擎/专业 API |
| 编程技术 | 代码生成、Debug、架构设计 | 代码专用模型 |
| 情感陪伴 | 倾听、建议、心理疏导 | 情感微调模型 + 安全边界 |

## 三、数据流与隐私设计

### 隐私优先原则
```
本地优先架构：
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│   本地设备    │ ←→ │  本地数据库   │ ←→ │  可选云端备份 │
│ (敏感数据)   │     │ (SQLite/向量) │     │ (端到端加密) │
└──────────────┘     └──────────────┘     └──────────────┘
```

- **敏感记忆**（家庭、财务）本地存储，不上云
- **云端同步**采用端到端加密，服务商无法解密
- 用户拥有完整数据导出权（JSON/CSV 格式）

## 五、功能迭代路线图

```
Phase 1 (MVP)：基础对话 + 聊天记录存储 + 简单记忆
Phase 2 (1个月)：个人知识库 + 文档上传问答
Phase 3 (2个月)：多Agent能力（日程、搜索、编程）
Phase 4 (3个月)：情感记忆 + 主动提醒（"你上次说这周要..."）
Phase 5 (长期)：跨设备同步 + 语音交互 + 本地大模型
```

## 六、关键设计要点

1. **记忆不是越多越好** — 需要遗忘机制，定期清理低权重信息
2. **主动 vs 被动** — 系统应在合适时机主动提醒（如"你上周提到要复习考试"），但避免过度打扰
3. **人格一致性** — 长期记忆应影响 AI 的回应风格（对内向用户更温和，对技术用户更直接）
4. **可解释性** — 用户可问"你为什么这样建议？"，系统展示依据的记忆/知识来源

## 七、快速启动建议

如果你想立即开始，最低配置方案：
- **前端**：一个简洁的 Web 聊天界面
- **后端**：FastAPI + SQLite 存储聊天记录
- **AI**：调用 Claude/GPT API（或本地 Ollama 跑 Qwen）
- **记忆**：每次对话后让 AI 总结关键信息存入数据库
- **知识库**：先用简单的关键词搜索，后续升级向量检索
