## 背景
SunChat 记忆系统当前"本地查询不够准确",实测与代码审查定位出 6 个环节问题:
1. **数据缺口**:SQLite 24 条活跃记忆,Chroma 仅 9 条向量——15 条永远召不回(历史 add 失败被吞、或模型切换后未重建);`create_memory` 在 Chroma 写失败时仍保留 vector_id 指向不存在的向量
2. **注入无过滤**:流式/非流式主路径 `search_memories_by_analysis` 不做相似度阈值,不相关记忆也进 system prompt;带 0.3 阈值的旧函数 `build_memory_context` 是死代码
3. **嵌入模型对中文弱**:nomic-embed-text 中文语义区分度差,是召回漂移的最大嫌疑
4. **查询串质量差**:路由 keywords 空格拼接当向量查询(如"用户 名字"),碎词伤害语义检索
5. **无精确匹配兜底**:人名/数字/专有名词纯靠向量,BM25/关键词通道缺失
6. **排序无反馈 + 写入噪声**:importance/accessed_at/access_count 字段闲置,从不参与排序、从不更新;提取侧 confidence 均值仅 0.59,闲聊垃圾记忆挤占召回位

## 目标用户
单用户本地部署场景(config.LOCAL_USER_ID=1),数据不出本机(Ollama 本地推理)。

## 核心场景
- S1 用户问"我叫什么/我喜欢什么" → 应稳定召回对应记忆(当前受数据缺口+嵌入模型影响不稳定)
- S2 用户问"我上次说的那件事" → episodic 记忆按时间新旧+相关度排序,不按 importance 一刀切
- S3 含专有名词/数字的查询("我说过股价多少来着") → 精确匹配兜底
- S4 切换嵌入模型(设置页已有 rebuild-vectors 入口)→ 向量库与 SQLite 保持一致,不再出现半重建状态
- S5 跑评测脚本 → 给出改造前/后 hit@k、无关节注入率对比数字

## 功能点
| 编号 | 描述 | 优先级 |
|---|---|---|
| FR-1 | 一致性自愈:对账 SQLite↔Chroma,活跃记忆缺向量自动重嵌入补齐;create_memory 写 Chroma 失败时不落悬空 vector_id(可回滚/标记) | P0 |
| FR-2 | 统一注入路径:检索后按相似度阈值过滤 + top_k 截断后再注入 prompt;删除死代码 `build_memory_context`;阈值/top_k 进 config | P0 |
| FR-3 | 嵌入模型升级为中文更强的模型(候选 bge-m3),切换后强制引导重建向量库 | P0(依赖 C1) |
| FR-4 | 查询串构建优化:原始用户输入为主查询串,keywords 仅作辅助/加权,不再碎词拼接 | P1 |
| FR-5 | 混合检索:关键词(BM25 或 SQLite FTS5)与向量各取 topN,RRF 融合;向量通道故障时保留现有关键词回退 | P1(依赖 C2) |
| FR-6 | 排序融合与反馈:final = α·相似度 + β·importance/10 + γ·时间衰减;检索命中后更新 accessed_at/access_count 并纳入排序 | P2(依赖 C3) |
| FR-7 | 写入侧收紧:confidence/importance 低于阈值的提取结果不落库,降低库内噪声 | P2 |
| FR-8 | 评测集与回归:构造 ~30 条本地问答评测集(golden set),脚本输出 hit@1/hit@3/无关节注入率,支撑前后对比 | P1 |

## 边界与非目标
- 明确包含:记忆读写链路(memory_service/core memory_*、chat_service 注入点)、config、必要的前端设置项微调
- 明确不做:知识库(KBFile)检索改造、agent 工具链路、多用户/权限、云端同步、向量库换引擎(继续用 Chroma)、prompt 文案大改

## 验收标准
| 编号 | 标准(可验证) | 验证方式 |
|---|---|---|
| AC-1 | 对账脚本/启动自检报告 Chroma 向量数 == SQLite 活跃记忆数(悬空/缺失可检出并修复) | pytest:mock Chroma 制造缺口 → 对账后相等 |
| AC-2 | 注入的记忆均 ≥ 阈值;评测集"无关节注入率"较基线下降 | 单测 + 评测脚本输出 |
| AC-3 | 评测集 hit@3 相对改造前提升(目标 ≥15pp,基线以改造前实跑为准) | 评测脚本前后对比报告 |
| AC-4 | "我叫什么/我喜欢X"类查询实机稳定召回正确记忆 | 实机手工用例 + 后端日志证据 |
| AC-5 | 全量 pytest(离线 mock)通过;新增检索/融合/对账逻辑有单测覆盖 | CI/本地 pytest 全绿 |
