## A-4 "逐 90° 试探、取第一个能检出/最像站立的"会选错(已确认,设计关键约束)
朴素方案=四向各试一次 MediaPipe,取可检出者。实测证伪:
- [RUN] 真人帧(246-A/B/C/D)在**生产门槛 0.5**下的四向检出与头向(鼻/髋/踝 y 序硬几何):
  ```
  246-A: 0°:横H-   逆90:竖H-   180:--     顺90:--
  246-B: 0°:横H-   逆90:竖H-   180:横H+   顺90:--
  246-C: 0°:横H-   逆90:竖H-   180:横H-   顺90:竖H+
  246-D: 0°:横H-   逆90:竖H-   180:横H-   顺90:竖H+
  238-A: 0°:竖H+   逆90:横H-   180:竖H-   顺90:横H+
  (H+/H-=头朝上/朝下;--=该朝向检不出人体)
  ```
- [RUN] 由表可见:①"A 帧转正后(逆90,竖)在门槛 0.5 下仍报头朝下"——错误朝向也能检出并
  给出反向几何;②真正 upright(顺90)在门槛 0.5 下**检不出**,降到 0.15 才出且 vis 仅
  **0.70**(0.5 档完全静默缺席)→ "取第一个可检出"会把横躺/头朝下的档当成有效解;
  ③MediaPipe lite 对朝向**敏感且非单调**,不可用"检不出=朝向错"作为可靠判据
- 结论 C-A4:判朝向**不能靠"能否检出"或检出次序**,必须在给定检出上用人身几何向量判;
  且阈值/检出可得性不能反过来决定旋转解,否则 R-3(多重门槛)与 A-3 会叠加误拒。

## A-5 以"人自身头脚轴"为基准的估算是可靠的(已确认,作为实现依据)
用户指令:不以横屏/竖屏/容器元数据为依据,**以人体自身朝向为准,头朝上脚朝下**。
- [RUN] 估算器:`u = 单位化(肩中点 − 髋中点)`(躯干轴,即人身自身"上"方向);
  180° 歧义用**鼻在 u 上的符号**消解(鼻必在头侧);量化到最近 90°档
- [RUN] 实测(原图直接测,不预设朝向):
  ```
  246-A: |肩-髋|=113.1px  人体上方向偏竖直 -90.2° → 需逆时针 270°(即顺时针90°)
  246-B: 115.4px  -93.3° → 270°      246-C: 118.4px  -95.1° → 270°
  246-D: 134.2px  -87.1° → 270°      238-A(已正立): 84.0px -7.1° → 0°(判正确)
  ```
  四条横躺帧一致判"顺时针 90°",与 A-2/A-3 的 bbox/VL/独立转正结果吻合;
  已正立的 238-A 判 0°(不误转)
- [CODE] 躯干 |肩-髋| 在 4 帧为 113~134px(≈身高的 0.25 量级),远高于量化噪声;
  偏角落在 -87°~-95° 窄带,**不会**踩 45°/135° 量化边界(±10° 安全裕度)
- 结论 C-A5:人身向量法可行且自洽。设计要点:①在**原图检出的一次关键点**上算,
  不做四向试探;②多样本(多粗扫帧)**投票**并记录一致度;③无法判定(无检出/一致度低/
  角落在边界带)时**不转**,并在 quality 打透明度键,由报告声明,不给假转正。
