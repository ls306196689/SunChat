## 3. 优化设计

### 3.1 SSE 流式渲染（F1）
新增 `lib/sse.js`（fetch + ReadableStream 读 SSE）：
```js
export async function* streamChat(body, { signal } = {}) {
  const res = await fetch(`${API_BASE}/chat/stream`, {
    method:'POST', headers:{'Content-Type':'application/json'}, body:JSON.stringify(body), signal
  })
  const reader = res.body.getReader(); const dec = new TextDecoder()
  let buf = ''
  while (true) {
    const {done, value} = await reader.read(); if (done) break
    buf += dec.decode(value, {stream:true})
    let idx; while ((idx = buf.indexOf('\n\n')) !== -1) {
      const frame = buf.slice(0, idx); buf = buf.slice(idx+2)
      const line = frame.split('\n').find(l=>l.startsWith('data:'))
      if (!line) continue
      const data = line.slice(5).trim()
      if (data === '[DONE]') return
      yield JSON.parse(data)
    }
  }
}
```
`chat.js.sendMessage` 改造：
- 乐观插入 user 消息 + 空 assistant 占位（用**唯一 id**，如 `crypto.randomUUID()`，修 F3）。
- 迭代 `streamChat`：每帧 `delta` 追加到占位 assistant 消息 `content`（实时渲染）。
- 收到 `done` 帧结束；`error` 帧或异常 → 回滚占位、提示。
- 记忆/搜索开关照旧传参。

### 3.2 超时（F2）
- 流式请求用 `AbortController`，设**空闲超时**（如 60s 无新块才中断），而非总时长 30s。
- 非流式（保留作回退）axios 超时提到 60s。

### 3.3 记忆页真实渲染（F4）
- 后端 `GET /memories` 修好后（M1），`memory.js.fetchMemories` 直接渲染返回的行；加分页/类型/分类过滤 UI（已有参数，补上交互）。

### 3.4 Agent 入口（F6）
- Chat 页加"Agent 模式"开关：开启时 `sendMessage` 走 `/chat/agent`（非流式，返回 `tool_trace`），用一个可折叠面板展示"Agent 调用步骤"（工具名 + 结果摘要）。

### 3.5 清理（F5/F7）
- 删 `console.log` 调试残留。
- Markdown 渲染：流式期间用纯文本/简单渲染，完成后 `marked` 渲染；如需 v-html 引入 `DOMPurify` 净化（本次先不引入新依赖，保持纯文本+完成后 marked，评估 XSS 面）。
