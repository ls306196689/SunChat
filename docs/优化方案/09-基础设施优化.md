## 3. 优化设计

### 3.1 事件循环阻塞（I1）
- 所有**非流式**路由 `async def` → `def`：FastAPI 自动把同步 `def` 路由丢进**线程池**执行，阻塞 `requests` 不再卡事件循环。
- 流式路由（`/chat/stream`）用同步 generator + `StreamingResponse`（Starlette 自动线程池迭代），同样不阻塞。
- 唯一保持 `async def` 的：纯快操作（如 whoami、health 的缓存读取）——实际上 health 探测是阻塞的，也改 `def`。

### 3.2 每请求 Session（I2）
采用标准 FastAPI 模式：
- `get_db` 保留为 `Depends` 依赖（yield session，结束 close）。
- **路由**签名加 `db: Session = Depends(get_db)`。
- **service 方法**不再持 `self.db`，改为接收 `db` 参数：`memory_service.search_memories(db, user_id, ...)`、`chat_service.process_message(db, ...)`、`knowledge_service.process_file(db, ...)` 等。
- service 仍是单例（持有 chroma_client 等无状态资源），但 DB 操作全部走传入的 `db`（每请求一个 Session，请求内跨 service 复用同一 Session）。
- **后台任务**（记忆异步提取）：BackgroundTask 里**自建 Session**（`next(get_db())` 用完 close，或用 `SessionLocal()`），不复用已关闭的请求 Session。
- 删除各 service `__init__` 里的 `self.db = next(get_db())`。
> 影响面：3 个 service 的多数方法 + 4 个路由。集中在批次 0 一次性改完，改完立即跑全量测试。

### 3.3 启动生命周期（I3/I4）
[main.py](../../backend/app/main.py) 加 `lifespan`：
```python
@asynccontextmanager
async def lifespan(app):
    # 1. 确保数据目录存在（绝对路径）
    # 2. init_db() 建表
    # 3. 迁移：habit 拼写、KBFile.storage_path 列（ALTER TABLE 兜底）
    # 4. 预建 Chroma collection
    # 5. Ollama 自检（is_available，记日志）
    yield
    # 关闭资源
app = create_app(lifespan=lifespan)
```
- `config.py` 路径全部基于 `Path(__file__).resolve().parent`（backend 根）解析为绝对路径。

### 3.4 统一 LLM/Embedding 客户端（I5）
- 保留 [core/llm.py](../../backend/core/llm.py) 为唯一 HTTP 客户端（Ollama `/api/chat`、`/api/embed`、`/api/tags`），用 `requests.Session`（连接池 + 默认超时 + `tenacity` 重试）。
- [core/embedding.py](../../backend/core/embedding.py) 的 `embed` 委托 `core/llm` 的底层 `_post`，新增 `embed_batch`（`/api/embed`）。
- [agent/llm.py](../../backend/core/agent/llm.py) 的 `AgentLLM` 改为**复用** `core/llm`（不再自己 `requests.post`），只保留消息组装/工具逻辑。

### 3.6 依赖瘦身（I7）
[requirements.txt](../../backend/requirements.txt) 删除零引用项：langchain、langchain-community、langchain-ollama、langchain-text-splitters（间接）、sentence-transformers、prometheus-client、SpeechRecognition、pydub、alembic、python-jose、passlib、aiohttp、aiosqlite（若用同步 sqlite 则 aiosqlite 可去——确认后用同步）。保留：fastapi、uvicorn、sqlalchemy、chromadb、requests、pydantic、pydantic-settings、python-multipart、python-dotenv、pypdf（替 PyPDF2）、ddgs（替/补 duckduckgo-search）、tenacity。
> 原则：**只删确定零引用的**；删除后跑全量测试 + 应用冷启动验证。

### 3.7 其它（I8/I9）

- `print(...)` 改 `logger.*`（knowledge_service、search_service）。
