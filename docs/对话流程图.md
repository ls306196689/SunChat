# SunChat 对话流程图

```mermaid
sequenceDiagram
    participant User as 用户
    participant Frontend as 前端 ChatStore
    participant Backend as 后端 API
    participant Memory as 记忆服务
    participant Chroma as Chroma 向量库
    participant Search as 搜索服务
    participant LLM as 大模型 Ollama
    participant DB as SQLite 数据库

    User->>Frontend: 输入消息 "我叫孙鹏飞"
    Frontend->>Frontend: 乐观更新 (用户消息 + 占位 AI)
    Frontend->>Backend: POST /chat/messages
    Note over Backend: Step 1: 记录用户消息
    
    Backend->>Memory: search_memories(query, top_k=3)
    Memory->>Chroma: 查询向量 (768维)
    Chroma-->>Memory: 相似度结果
    Memory-->>Backend: 记忆上下文 (0-3条)
    
    Backend->>Search: route_query(query, memories)
    Search->>Search: 意图分类 (news/academic/code/general)
    Search->>Search: 增强查询 (添加记忆背景)
    Search-->>Backend: 搜索上下文
    
    Backend->>Backend: 构建 Prompt
    Note right of Backend: 系统提示 + 记忆 + 搜索<br/>+ 用户消息
    
    Backend->>LLM: generate(prompt, system)
    LLM-->>Backend: AI 响应
    Note over Backend: Step 5: LLM 响应
    
    Backend->>DB: 保存用户消息
    Backend->>DB: 保存 AI 消息
    Note over Backend: Step 6: 存储消息
    
    alt 记忆功能开启
        Backend->>Backend: extract_memories(content, response)
        Backend->>LLM: 记忆提取 Prompt
        LLM-->>Backend: {"memories": [...]}
        Backend->>Memory: create_memory(memories)
        Memory->>Memory: 生成向量
        Memory->>Chroma: 写入向量
        Memory->>DB: 保存元数据
    end
    
    Backend-->>Frontend: 返回响应 + 新记忆
    Frontend->>Frontend: 替换占位消息
    Frontend->>User: 显示 AI 回复
```

## 关键步骤详解

### Step 1: 用户消息处理
```
日志: [CHAT] Step 1/6: 处理用户消息
```

### Step 2: 记忆上下文构建
```
输入: query="我叫孙鹏飞", top_k=3
处理: search_memories → Chroma 检索
输出: memory_context = [{"content": "...", "similarity": 0.85, ...}]
日志: [CHAT] Step 2/6: 构建记忆上下文 - 上下文数:1
```

### Step 3: 搜索上下文构建
```
输入: query="我叫孙鹏飞", memories=[...]
处理: route_query → 意图分类 + 查询增强
输出: search_context = {"intent": "general", "query": "..."}
日志: [CHAT] Step 3/6: 搜索上下文 - intent:general
```

### Step 4: Prompt 构建
```
系统提示: 你是一个智能助手。请回答用户问题。

用户背景信息（基于语义检索的记忆）：
- 用户喜欢 Python (相似度: 0.85)
- 用户熟悉 Vue (相似度: 0.72)

搜索上下文：用户查询 (用户背景: ...)
用户: 我叫孙鹏飞

AI:
```

### Step 5: LLM 调用
```
模型: qwen3-coder-next:q8_0
输入: 完整 prompt
输出: "好的，孙鹏飞，记住了！😊 有什么我可以帮您的？"
日志: [CHAT] Step 5/6: 调用 LLM 生成响应
```

### Step 6: 消息存储
```
存储:
- user_msg: {"role": "user", "content": "我叫孙鹏飞"}
- ai_msg: {"role": "assistant", "content": "好的，孙鹏飞..."}
日志: [CHAT] 用户消息已存储, [CHAT] AI 消息已存储
```

### Step 7: 记忆提取 (可选)
```
输入: user_message="我叫孙鹏飞", ai_response="好的，孙鹏飞..."
Prompt: 从对话中提取记忆
LLM 输出: {"memories": [{"content": "用户叫孙鹏飞", "importance": 10}]}
处理: create_memory → 生成向量 → Chroma 写入 → SQLite 写入
日志: [CHAT] 记忆提取完成 - 提取到 1 条记忆
```
