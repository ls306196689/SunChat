# SunChat 对话交互流程说明

## 一、整体架构

```
用户输入 → 前端 UI → 后端 API → 智能处理 → 大模型 → 响应 → 前端显示
```

## 二、前端流程 (frontend/src/stores/chat.js)

### 1. 用户输入
- 用户在聊天界面输入消息
- 按 Enter 或点击发送按钮

### 2. 乐观更新
```javascript
// 立即在 UI 中显示用户消息
const userMsg = {
  id: timestamp,
  role: 'user',
  content: '用户输入的内容',
  created_at: new Date().toISOString()
}
messages.value.push(userMsg)

// 添加占位的 AI 消息（loading 状态）
const placeholderMsg = {
  id: timestamp + 1,
  role: 'assistant',
  content: '',
  created_at: new Date().toISOString()
}
messages.value.push(placeholderMsg)
```

### 3. 发送请求
```javascript
await request.post('/chat/messages', {
  session_id: currentSession.value.session_id,
  content: '用户消息',
  memory_context: true,   // 是否启用记忆
  search_enabled: true    // 是否启用搜索
})
```

### 4. 处理响应
```javascript
// 从响应中提取 AI 内容
const aiContent = response?.response || response?.data?.response || ...

// 替换占位消息
const idx = messages.value.findIndex(m => m.id === placeholderId)
if (idx !== -1) {
  messages.value[idx].content = aiContent
}
```

## 三、后端流程 (backend/services/chat_service.py)

### Step 1/6: 处理用户消息
```
[CHAT] Step 1/6: 处理用户消息 - 用户:1, 会话:123, 内容:你好...
```
- 记录用户消息
- 记录日志: `chat_logger.log_message_send()`

### Step 2/6: 构建记忆上下文
```
[CHAT] Step 2/6: 构建记忆上下文 - 上下文数:2
```

**流程:**
1. 调用 `build_memory_context(user_id, query, top_k=3)`
2. 调用 `memory_service.search_memories()`
   - 生成查询向量 (768维)
   - Chroma 向量相似度搜索 (top_k * 2 = 6)
   - 过滤相似度 > 0.3 的结果
3. 格式化结果:
```python
[
  {
    "id": "mem_xxx",
    "content": "用户喜欢 Python",
    "similarity": 0.85,
    "type": "semantic",
    "category": "skill"
  },
  {
    "id": "mem_yyy",
    "content": "用户熟悉 Vue",
    "similarity": 0.72,
    "type": "episodic",
    "category": "skill"
  }
]
```
4. 记录日志: `chat_logger.log_memory_context()`

### Step 3/6: 构建搜索上下文
```
[CHAT] Step 3/6: 搜索上下文 - intent:general
```

**流程:**
1. 调用 `build_search_context(query, memories)`
2. 调用 `search_service.route_query(query, {"memories": memories})`
3. 意图分类 (基于关键词):
   - `最新|今天|刚刚|news` → `"news"`
   - `论文|研究|学术|paper` → `"academic"`
   - `价格|购买|评测` → `"commerce"`
   - `代码|bug|API|github` → `"code"`
   - 其他 → `"general"`
4. 增强查询 (如果有记忆):
   ```
   用户查询 (用户背景: 记忆1 记忆2 记忆3)
   ```
5. 返回:
```python
{
  "intent": "general",
  "query": "用户查询 (用户背景: ...)"
}
```

### Step 4/6: 构建 Prompt
```
[CHAT] Step 4/6: 记忆上下文已添加到系统提示
[CHAT] Step 4/6: 搜索上下文已添加到系统提示
```

**Prompt 结构:**
```
你是一个智能助手。请回答用户问题。

用户背景信息（基于语义检索的记忆）：
- 用户喜欢 Python (相似度: 0.85)
- 用户熟悉 Vue (相似度: 0.72)

搜索上下文：用户查询 (用户背景: ...)

用户: 用户输入的内容

AI:
```

### Step 5/6: 调用 LLM
```
[CHAT] Step 5/6: 调用 LLM 生成响应
[CHAT] LLM 响应长度:220
```

**流程:**
1. 调用 `ollama_service.generate(full_prompt, system_prompt)`
2. 使用模型: `qwen3-coder-next:q8_0`
3. 返回 AI 响应内容

### Step 6/6: 存储消息
```
[CHAT] 用户消息已存储
[CHAT] AI 消息已存储
```

**流程:**
1. 创建 Message 记录 (role="user")
2. 保存到 SQLite
3. 创建 Message 记录 (role="assistant")
4. 保存到 SQLite

### Step 7/6: 提取新记忆 (可选)
```
[CHAT] Step 6/6: 开始从对话中提取新记忆
[CHAT] 记忆提取完成 - 提取到 1 条记忆
[CHAT]   提取的记忆1: 用户叫孙鹏飞..., 类型:semantic, 类别:name, 评分:10
[MEMORY] 创建记忆 - 用户:1, 类型:semantic, 分类:name, 内容:用户叫孙鹏飞..., 状态:成功
[MEMORY] 创建记忆成功 - memory_id:mem_xxx, vector_id:vec_xxx
[CHAT] 处理完成 - 响应长度:220, 新记忆:1
```

**流程:**
1. 调用 `generate_memory_from_message(content, response_content)`
2. 构建记忆提取 Prompt (见下文)
3. 调用 LLM 提取记忆
4. 解析 JSON 响应
5. 调用 `memory_service.create_memory()`
   - 生成向量 (768维)
   - 写入 Chroma
   - 写入 SQLite
6. 返回新记忆列表

## 四、记忆提取 Prompt

```python
prompt = f"""你是一个智能记忆提取器。请从以下对话中提取对用户有价值的记忆信息。

用户消息: {user_message}
AI 回答: {ai_response}

请以 JSON 格式输出提取的记忆，格式如下：
{{
    "memories": [
        {{
            "content": "提取的记忆内容（完整、明确的陈述）",
            "type": "semantic/episodic",
            "category": "preference/skill/event/work/name/hobby",
            "importance": 1-10
        }}
    ]
}}

要求：
1. 优先从用户消息中提取明确的事实信息
2. 用户主动告诉你的信息（如名字、偏好、背景）是重要的记忆
3. 用户描述的事实、观点、经历都应提取
4. 即使是简单的陈述，只要包含有用信息就提取
5. 如果用户提供了名字，必须以"用户叫[名字]"格式存储，重要性必须是 10
6. 对于用户提问，如果提问本身透露了信息（如"我叫什么"暗示用户想提供名字），也应提取
7. 即使没有明确的个人相关信息，如果对话中有任何有用的信息，也应提取
8. 如果确实没有任何有效信息，返回空数组 []
请直接输出 JSON，不要有任何额外文本。
"""
```

## 八、关键特性

1. **记忆增强**: 通过语义检索检索相关记忆，提供给 LLM 上下文
2. **智能路由**: 根据用户意图自动增强搜索查询
3. **自动提取**: 从对话中自动提取新记忆，实现"记得住"
4. **日志追踪**: 完整的日志记录，便于调试和分析
5. **流式响应**: 支持流式输出，提升用户体验
6. **容错机制**: 记忆搜索失败时自动回退到 SQLite 关键词搜索
